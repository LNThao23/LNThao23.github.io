# Portfolio typography standard

| Element | Font | Desktop size | Mobile size |
| --- | --- | --- | --- |
| Brand / H1 (cover title) | Big Shoulders Display, 900 | 60px | 48px |
| H2 (section title) | Big Shoulders Display, 900 | 48px | 36px |
| H3 (card or subsection title) | Big Shoulders Display, 800 | 28px | 28px |
| H4 (small heading) | Big Shoulders Display, 700 | 20px | 20px |
| Body | Afacad, 400–700 | 12px | 12px |
| Cover / hero description | Afacad, 400–700 | 16px | 16px |
| Label / kicker / caption | Afacad, 700 | 16px | 16px |
| Navigation | Afacad, 400 (normal case) | 16px | hidden on mobile where applicable |

The shared rules are implemented in `typography.css` and loaded by every HTML page.

All buttons and button-style links use 8px vertical and 16px horizontal padding. Home's View Project and About Me buttons are the exception, using 4px vertical padding while sharing the same width.
